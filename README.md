The Tree of Birds script is used for when the player gets close enough to the birds and makes them appear. During the gameplay, the player is a monkey and they can create a seed and throw seeds at a tree full of birds. In order to achieve this, there are countless things needed including an array and vectors. In this script, the array (Bird[] _sparrow) stores a collection of all the bird objects and loops through each one every frame. The vectors specifically Vector 3 positions are used to calculate the exact space between the player and the birds in the tree. Once the player moves within the set distance (_interactDistance), the birds GameObject is activated.
